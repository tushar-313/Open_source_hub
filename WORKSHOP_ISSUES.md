# Workshop Issue Bank

These are the planned GitHub Issues for the workshop repository.

## Beginner — good first issue

1. Add your name to CONTRIBUTORS.md
2. Add GitHub profile link to contributor list
3. Fix a typo in README.md
4. Add a Git resource to the Resources section
5. Improve the hero section description
6. Add one Open Source benefit
7. Add or improve image accessibility if an image is introduced
8. Improve footer content
9. Improve spacing in the Resources section
10. Improve button styling

## Easy

11. Make contributor cards consistent
12. Improve mobile layout
13. Add a hover effect to resource cards
14. Improve typography hierarchy
15. Improve responsive navigation
16. Improve accessibility of interactive elements

## Medium

17. Add a CSS-only light/dark theme
18. Create a responsive contributors grid
19. Improve complete mobile responsiveness
20. Redesign the Resources section

Only the first beginner issue should be the recommended live workshop task, so participants can complete the entire Fork → Clone → Branch → Change → Commit → Push → PR workflow quickly.
